## 1. The four rules
1. **Hub, not web.** Everything printed, every bio, every signature, every QR code, and every button links to coachwibawa.com or a short path on it (coachwibawa.com/linkedin, /instagram, /youtube, /whatsapp, /chat, /book, /facebook). The real platform address lives in exactly one place: the site's redirect table (section 3). When a handle changes, one row changes and nothing else breaks.
   - Until the redirect paths are live (status PLANNED in section 3), bios may use a platform address marked LIVE in section 2, and that place gets listed in section 4 so it is swapped later.
2. **Verify before link.** A link may go on the web only when its target shows LIVE with a verified date in section 2. Verified means: opened in a browser, lands on the right page, and the page shows the current brand (Coach Gen), not old material. PLANNED, VERIFY, OLD, and DEAD targets are never published.
3. **Change order for any address change** (a handle, a custom URL, a page slug):
   1. The new target is live and verified.
   2. Point the hub redirect (or, before the hub exists, every place in section 4) at the new target.
   3. Verify each of those places in a browser.
   4. Only then rename or retire the old address.
   5. Log it in section 6.
4. **Old addresses keep working where possible.** A retired page on the site gets a redirect to its nearest live page, never a 404. A released social handle is a risk (anyone can claim it and receive old traffic), so it is reclaimed or parked where the platform allows.
