## 0. READ THIS FIRST (rules for any agent using this file)

1. **Consent.** Every client in this file has given Coach Gen permission to use their session content. You do not need to ask again. The privacy limits in section 5 still apply: permission covers the lines in this file, not every detail from the sessions.
2. **Real name vs. composite name.** The Source field holds the client's real name. Section 2B says exactly when to print the real name and when to print the composite name. When unsure, print the composite name.
3. **On client-facing pages, print the "Speaker in print" name.** That is the composite name (see section 2 and 2B). Coach Gen's own lines print as "Coach Gen."
4. **Use the Text exactly as written.** Do not paraphrase, shorten, add words or "improve" it. The wording is already simplified for readers whose English is a second language.
5. **Style rules for anything you add around a quote:** no em dashes, no semicolons, no emojis. Simple English. Short sentences.
6. **This file is add-only.** Never delete or shorten an entry. To stop using one, set `Status: RETIRED` and add a one-line reason.
7. **Composite disclaimer.** Print this once, on the intro page: "The people in this workbook are composites of real coaching sessions. Names and details changed." End cards may repeat it in small italic under the testimony.
8. **Translated lines.** Entries marked `Translated` came from an Indonesian-language session. They are faithful simple-English translations, not word-for-word.
9. **Expanded lines (added 2026-10-05).** Section 3H holds expanded versions of the client lines, written as full sentences a reader can follow without the session around them. For print, use the 3H line where one exists. The T-entry it came from stays as the source record. Coach Gen's reasoning (5 Oct): a line that only makes sense inside hours of coaching "stands in the midpoint between being vague and being relatable", so readers don't understand it and the person can still recognise themselves. The method is Book Rules R3b: the core comes from the session, the surface is built. Every 3H entry lists its built details.
10. **Testimony vs. client words (Coach Gen, 5 Oct).** They are different things and live in different slots. **Client words** are process lines: how a step felt, where the person got stuck, what they did about it. His example: "I got confused here at the start because..." They go beside the field they help with (MARGIN-HINT, REASSURANCE-BOX, TITLE-PAIR). **Testimony** is the person's verdict on the whole Law: what it did for them. It goes on the END-CARD only. His words: "testimony is different from client words. testimony is about just testimony... client words is 'I got confused here at the start because'." Never put a testimony line in a margin, or a process line on an end card.
   Clarified 2026-10-07: testimony means **before and after testimonials**, not praise of the coach. His words: "praise, more like before and after testimonials." Every END-CARD prints a Before line and an After line from the same person, in the style already used for Melina's before and after row on the Law 5 title page: Before in muted grey, After in the accent colour. Rule P8 (no praise of the coach) stands.

## 1. PLACEMENT SYSTEM (how faces and quotes work in this workbook)

The workbook uses faces as **companions, not endorsers**. A face on a working page shows how someone did this step. It never says "this program works."

| Rule | What it means for layout |
|---|---|
| P1. Companions, not endorsers | Working pages only get process lines (how it felt, where they got stuck). "It worked" lines live only on END-CARDs. |
| P2. Put the face where the reader gets stuck | Small portrait + one line in the margin, beside the exact field it helps with. Never at the top of the page under the title. |
| P3. Quote the struggle, not the result | On working pages, prefer lines about doubt, getting stuck, starting slow. |
| P4. Match every quote to its page | A line only goes on the page for the exercise it came from. The "Law / Field" note on each entry tells you which. |
| P5. Pair example and blank pages | Filled example page, then its blank page right after. Not all examples first, then all blanks. |
| P6. Recurring cast | The same 2 or 3 composite people appear across all 5 Laws. The reader follows them. See section 2. |
| P7. Disclaimer once, up front | See rule 7 above. |
| P8. Never use | Bolded money or numbers, praise of the coach, credibility or press pages, notes pages padded with testimony. |

### Slot types (the `Slot` field uses these names)

| Slot | What it is | Where it sits |
|---|---|---|
| `INTRO` | Framing line for the whole workbook | Intro page, near the cover tagline |
| `INTRO-LETTER` | Coach Gen's own voice, opening letter | Intro letter page |
| `HOW-TO-USE` | Proof the workbook works without a coach | "How to use this workbook" box on intro |
| `TITLE-PAIR` | Before line + after line from one person | Law title page (divider), small, below the Law name |
| `MARGIN-HINT` | Small face + one line beside one field | Blank worksheet page, margin, next to the named field |
| `EXAMPLE-FILL` | Content written inside a filled example worksheet | The case study / example page for that exercise |
| `REASSURANCE-BOX` | "You might be thinking..." box: a doubt + what happened next | Bottom of a working page or on the reflection page |
| `WHAT-CHANGED` | Small, checkable wins. No numbers. | Box on the Law's end-card page, above the testimony |
| `END-CARD` | The one outcome testimony per Law | Dark card at the end of each Law (like David's Law 1 page 4) |
| `COACH-BOX` | Coach Gen's own voice, marked as his | Side box on a working page, labeled "From Coach Gen" |

### Kind tags (the `Kind` field)

`FIT` the client names the problem the book solves. `BEFORE-AFTER` a shift inside one session. `SMALL-WIN` a checkable win with no numbers. `HONEST-PARTIAL` a half-finished, honest result. `WORKS-ALONE` the client used the tool without the coach. `COACH-VOICE` Coach Gen's own proof. `DOUBT` a reader-style doubt for reassurance boxes. `MECHANISM` explains why it works, no promise. `STUCK` a stuck symptom. `MISCONCEPTION` a wrong belief. `MISEXECUTION` doing it wrong while trying. `HIDDEN-REASON` what the old pattern protects. `IDENTITY` a who-I-am shift. `RESOURCE` a tool or structure.
