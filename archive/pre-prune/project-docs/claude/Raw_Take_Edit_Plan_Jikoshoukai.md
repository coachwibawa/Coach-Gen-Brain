Estimated length: about 85 seconds.

Cut points come from the word timings, with about 0.15 s of room left before the first word and after the last, so no word gets clipped and no dead air stays in.

**Captions**
- Japanese parts: Japanese captions, 2 to 5 words a chunk.
- Indonesian skits: the Indonesian line large, the Japanese meaning smaller underneath, and the situation label at the top. Learners need all three.
- Japanese text needs a Japanese font. Bebas Neue and Anton have no Japanese letters. Hiragino Sans (on every Mac) is the first one to test.

**How it is built in Concat:** import the file once, place it 18 times, trim each copy to its in and out points, line them up end to end, set the frame (zoom and position) per clip, add captions and labels, export. Same tools as the trial, with real video instead of a still.

## 3. Problems found in the raw file

1. **Low resolution: 478 x 850.** WhatsApp shrank it. On a 1080 x 1920 Reel it will look soft. Need the original file from the phone.
2. **Framing moves.** You drift left and right between takes (for example around 3:05 to 3:20 and 4:00, partly out of frame). I can zoom in and re-center each clip, but zooming a 478-pixel file makes it softer still. The original file solves this too.
3. **Mic takes the right third of the frame.** Fine for this style, but it limits how far I can re-center.
4. **Possible phone in hand around 2:40.** Only matters if a kept take shows it. None of the chosen takes are in that window.

## 4. Lessons for mixed-language transcription (keep for every future raw take)

- Whisper's automatic language choice fails on mixed takes. It turned a Japanese line into Indonesian. Fix: transcribe once, split by pauses, then run each piece again with its language forced (Japanese or Indonesian) and keep the cleaner one.
- Whisper invents words over silence ("thanks for watching"). Fix: check every line against the silence map before using it.
- The "medium" model is clearly better than "small" on Japanese (small wrote 元 for げん and 倍 for 場合). Use medium. It took 3 minutes for a 6.5 minute take.
- Word timings inside a merged or wrongly detected segment are wrong. Recheck those pieces separately before cutting on them.

## 6. Build log, 2026-10-22 (autopilot run)

Output: `Desktop/Jikoshoukai Reel v2.mp4` (74.9 s, 1080 x 1920) and the saved Concat project `Desktop/Jikoshoukai Reel`. v1 had one mistake, see below. Total build time about 20 minutes, with Coach Gen approving only the exports.

What was done:
- Each kept take was transcribed again on its own, with its language forced, to get word timings for the captions.
- Raw file placed once, split at 38 points, unused takes removed, the 19 kept pieces moved into the new order.
- Three caption layers plus the situation label: Japanese narration (Hiragino Sans, white), Indonesian line (Hanken Grotesk, white), Japanese meaning (Hiragino Sans, yellow), label (yellow box, top).
- Three takes re-framed where Coach Gen drifted off center (Kenalin, umur 27, anime line).
- Export checked by transcribing the finished file and looking at a frame every 3 seconds.

Mistake caught by the check and fixed in v2:
- The "でも、日本語と同じで…" take had a false start before a pause. v1 kept both, so the line was said twice. v2 keeps only the restart (last-take rule applies inside a take too).

Lessons for the next autopilot run:
- **Last-take rule applies inside one take as well:** a pause followed by the same words again means the first part goes.
- **Always transcribe the export and compare.** It caught the doubled line. Whisper can also invent a repeat on the finished file (it did on the 会議 line), so check any doubt against the raw file before cutting.
- Concat `edit_apply` (batch) did not accept its command from this connection (it arrived as text). Typed tools work: one split per cut point, then one remove and one move call.
- Re-framing math: on screen position = 0.5 + (position in raw - 0.5) x scale + offsetX. Zooming pushes an off-center face further out, so the offset must grow with the zoom.
- Hiragino Sans renders Japanese in Concat. Use it for all Japanese text.
- The WhatsApp copy (478 x 850) is soft at 1080 x 1920 and when zoomed. Original files from the phone fix this.
